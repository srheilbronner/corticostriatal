# Macaque cortico-striatal connectivity database
Anatomical and functional cortico-striatal connectivities (n=88)
From the literature and Heilbronner Lab, in macaques.
Connectivity has been registered to NMT1.2 space (Seidlitz). They are listed by source.
Further explanation can be found in:
Tang, W., Monko, M.E., Liu, Z. et al. Functional vs anatomical cortico-striatal connectivity in the macaque brain. Transl Psychiatry 16, 13 (2026). https://doi.org/10.1038/s41398-025-03757-x
